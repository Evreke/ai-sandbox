# ai-sandbox

Personal sandbox monorepo.

- [`pi/extensions/grill-deck`](pi/extensions/grill-deck) — interactive question deck extension for [pi](https://pi.dev). Published to npm as [`@evreke/pi-grill-deck`](https://www.npmjs.com/package/@evreke/pi-grill-deck): `pi install npm:@evreke/pi-grill-deck`
- [**pi-delegate**](https://github.com/Evreke/delegate) — multi-agent orchestration harness extension for [pi](https://pi.dev): spawn worker fleets (worktree/tab isolation), briefs, strict JSON reports, and a session-keyed watcher that wakes the orchestrator on report-ready / mailbox-question / worker-dead events. Lives in its own standalone repo since 2026-09 — this repo keeps no copy.
